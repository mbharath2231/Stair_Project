# Daily device handoff summaries

Each dated folder contains a Word guide to the day's experiments,
results, and next steps. When handing off to another device, create or
update that day's guide and push it with the code. Use
`YYYY-MM-DD/STAIR_Study_Guide_YYYY-MM-DD.docx` or a topic-specific name.

| Date | Summary | Outputs |
| --- | --- | --- |
| 2026-11-23 | [Clayton spatial correction study guide](2026-11-23/STAIR_Clayton_Study_Guide_2026-11-23.docx) | [Spatial validation archives](../../outputs/README.md#clayton-spatial-correction-and-nonlinear-models-november-23) |

Open the guides from a local checkout to use the project file links.
Extract the release archives into the repository root first when those
links point to generated outputs. See the [device setup guide](../CONTINUATION.md).
