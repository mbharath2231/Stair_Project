# Daily device handoff summaries

Each dated folder contains a Word guide to the day's experiments,
results, and next steps. When handing off to another device, create or
update that day's guide and push it with the code. Use
`YYYY-MM-DD/STAIR_Study_Guide_YYYY-MM-DD.docx` or a topic-specific name.

Extract the release archives into the repository root first when those
